## 1. 本轮边界

本轮不是丢弃历史模型，也不是将多个完整模型串联。唯一变量是输入观测处理：

```text
冻结 HRNet 中间特征
    -> 当前 V2/V3/V4 子集内的极线对应（Epipolar Transformer 思路）
    -> 有界、零初始化的射线方向修正
    -> 原 H76/RUMPL（锚点 + anchor-centered Pluecker）
    -> 后续若有效，再原样复用 E2 候选效用融合
```

明确保留：

- RUMPL 的射线表示、VFT/PFT 和相机布局泛化能力；
- H76 已验证的置信度三角化锚点、anchor-centered Pluecker 表示；
- E2 已验证的 3/4 视角候选效用融合；
- 现有真实 H36M 训练划分、S9/S11 测试协议与 action-equal MPJPE 口径。

本轮替换：旧 A1D/H21 输入修正，不改 H76 主干。Volumetric 仅保留为诊断上界，
不进入相机无关论文主线。

V2 的协议风险。本轮每个组合分别计算描述，严格禁止该泄漏。

## 3. 方法依据与差异

- 依据：Epipolar Transformer（CVPR 2020）使用中间图像特征在极线上做对应聚合；
- 适配：不生成固定世界体素，不加入相机 ID，不使用目标域 GT 做测试时优化；
- 与旧 RIGR 的差异：极线特征不直接回归最终 3D，而只修正 RUMPL 的输入射线；
- 与旧 D0/D1 的差异：旧射线修正只看几何/效用，正式测试均退化；新模块提供图像
  对应证据，并设置参数量相同的 geometry-only 对照。

## 4. 已完成的正确性检查

1. 每个 2/3/4 视角组合仅访问该组合内的 HRNet 特征；
2. 不使用相机 ID、世界体素或 GT 生成描述；
3. 输出头零初始化时，修正射线与输入逐元素完全相同；
4. 零修正重新运行 H76，修正前后输出最大差为 0；
5. 四视角任意置换最大输出差为 `2.38e-7 m`；
6. 小规模 1 轮冒烟训练的留出集变化：V2/V3/V4 约
   `-0.167/-0.175/-0.169 mm`。该数值只证明链路可学，不作为正式结果。

缓存导出时与当前重新推理在极少数弱相机对上最大有 `0.104 mm` 数值漂移，来源于
近乎平行射线的浮点敏感性；新模块的零修正与当前 H76 推理严格相同，因此不存在
基线被暗改的问题。正式结果同时报告缓存基线和同进程 identity 基线。

## 5. 正式实验矩阵

| 编号 | HRNet 极线描述 | 几何输入 | H76 | 用途 |
|---|---|---|---|---|
| P0 | — | 原射线 | 冻结 | H76 原基线 |
| P1 | — | 学习有界修正 | 冻结 | 同参数量 geometry-only 对照 |
| P2 | ✓ | 学习有界修正 | 冻结 | 本轮核心输入模块 |
| P3 | ✓ | P2 修正 | 同架构微调/重训 | P2 有效后才运行 |
| P4 | ✓ | P3 候选池 | P3 + E2 | 复用旧 E2，不重新发明融合器 |

晋级规则：

- P2 必须在 S9/S11 的 V2/V3/V4 平均优于 P1，才能说明图像极线证据有效；
- P2 至少两个视角数优于 H76，且不能用明显牺牲 V2 换 V4；
- 满足后生成 P3 的新候选池，再测试 E2 是否具有互补收益；
- 正式主表需要多种子，当前 seed 0 仅用于快速筛选。
