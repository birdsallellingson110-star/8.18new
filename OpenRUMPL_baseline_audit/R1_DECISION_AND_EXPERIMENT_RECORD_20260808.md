# R1 决策与实验记录（2026-08-08）

## 决策依据

- 当前主基线固定为 H76，三种子严格结果为 V2 `34.677±0.150`、V3
  `30.501±0.350`、V4 `29.710±0.549` mm。
- H76 诊断表明，V2 的相机对差异远大于视角数差异：`1-4=42.435`、
  `2-3=41.642` mm，而其余相机对约为 `30.5–32.3` mm。加入第三视角可
  挽救坏相机对约 `11–12` mm，但 V3 到 V4 仅再改善 `0.44–0.96` mm。
- H76 的三角化锚点本身不是最终答案：V4 锚点为 `41.388` mm，网络输出为
  `29.691` mm。主要剩余瓶颈在下肢和坏视角组合，不能直接用三角化替换
  RUMPL。
- 旧的全局 joint-view、RelativeViewFusion、时序模块都曾让全网共同微调，
  导致 H76 表示漂移并显著退化。因此 R1 不重写视角 token，也不解冻 H76。

## R1 方法

保留 H76 的三角化残差锚点、anchor-centered rays、Plücker 输入、原生 VFT、
PFT 和输出头。新增一个不使用相机 ID 的全骨架视角可靠性网络：

1. 将单个视角的 17 个关节嵌入拼接成完整骨架描述；
2. 以所有视角描述的均值作为集合共识；
3. 用“视角描述、与共识的有符号差、绝对差”预测每个视角的中心化可靠性；
4. 只把该可靠性加到每层 VFT 中融合 token 查询各视角 key 的 attention logits；
5. 每层使用独立的零初始化门控，训练开始时严格等价于 H76。

该设计对视角排列等变、对视角数量无关，不引入相机身份，因此保留相机泛化
目标。R1 暂不加入检测置信度或显式几何偏置，避免一次实验混入多个变量。

## 正确性检查

- 单元测试：V2/V3/V4 形状、中心化、视角置换等变、只修改融合查询行、
  零门控严格为零、梯度有限，全部通过。
- 使用真实 H76 checkpoint 构建“R1 关闭”和“R1 开启但门控为零”两个完整
  模型：308 个共有 state-dict key 逐元素相同；随机 V2/V3/V4 输入的最终输出
  逐元素完全相同。
- 训练范围检查：H76 冻结，仅新增模块和 12 个层门控可训练，共
  `2,754,829` 个参数。

- 若任一学习率在严格评估中稳定改善 H76，先检查门控与可靠性排序，再进行

## 最终严格结果与决策

以下均为同一 seed 0、同一真实 H36M 输入和同一严格 Table-2 action-equal
All-17 口径：

| 方法 | V2 | V3 | V4 | 相对 H76 |
|---|---:|---:|---:|---|
| H76 | 34.8163 | 30.4890 | 29.6913 | — |
| R1 `lr=1e-4` | 34.8179 | 30.4937 | 29.6785 | +0.0016 / +0.0047 / -0.0128 |
| R1 `lr=5e-4` | 34.8236 | 30.4905 | 29.6764 | +0.0072 / +0.0015 / -0.0149 |

负数表示误差降低。KP* 也只有最大 `0.0364` mm 的降低，仍远低于种子波动。
两个学习率学到的 12 层门控符号模式一致，但最佳模型的门控绝对值均值仅为
`0.00776` 和 `0.01548`。这说明优化器能接收到稳定方向，却找不到足以改变
结果的可靠性信号。

**决策：R1 失败，不做三种子、不解冻 H76、不与时序融合。** 无监督地从当前
骨架 token 猜视角质量，与 H76 已有注意力的信息高度重复。下一步进入 R2：
保留已经验证安全的融合行注入位置，但以现有 2D 检测置信度和跨视角重投影
残差提供显式可靠性依据；R2 先拆成置信度监督与几何一致性两个单变量实验，
不同时混合。

## R4：特征空间关节-视角残差校正（2026-08-09）

为针对 H76 诊断出的“坏视角只在部分下肢关节失效”，R4 不再修改 attention
logits，而是在进入原生 VFT 前直接校正每个 `(joint, view)` token：

```
x[j,v] <- x[j,v] + s[j,v] * w[j]
```

其中 `s` 是中心化的可靠性标量，`w[j]` 是每个关节独立的 256 维可学习方向。
`w` 零初始化，所以关闭门控时完整模型与 H76 严格相同；只训练 17×256 个
参数，H76 的 VFT/PFT/三角化残差头和相机无关性保持不变。

- R4a：`s` 为中心化的 2D 检测置信度；
- R4b：`s` 为跨视角射线一致性 logits；
- 两者互斥，不与前述 bias 或时序模块混合。

## R5：条件 MLP 残差（已实现，待运行）

R5 保留 R4b 的几何/置信度可靠性标量，但将固定方向替换为零输出的条件 MLP：

```
h = GELU(Linear([token, scalar]) + joint_embedding[j])
x' = x + Linear_zero(h)
```

输出层严格零初始化，因而完整模型加载 H76 时逐元素恒等；训练时仅更新该
小型 adapter（约 33k 参数），使残差方向能够依赖当前 token 内容和关节。R5a
使用置信度，R5b 使用几何一致性，互斥且不解冻 H76。

校正，直接针对 bottleneck audit 中“triangulation anchor 粗、RUMPL residual
head 负责大部分修正”的现象。

### R7 候选：融合后输出端（仅在 R6 后按结果启动）

代码中原有的 H81–H83 是全网微调，不能回答“输出端模块本身是否有益”。
因此准备了冻结 H76 的三条单变量控制：

1. `per_joint_residual_gate`：只学习 17 个最终 RUMPL 残差缩放系数，保持三角
   化锚点不变；
2. `joint_specific_head`：只学习零初始化的每关节 3D 校正头；
3. `post_pft_graph_residual`：只学习零初始化的 H36M 骨架邻接消息残差。

三者均保持 H76 的 tri-anchor、Plücker 输入和视角采样，且使用 R6 修正后的
冻结主干模式。启动器为
`launch_R7_output_side_frozen_20260809.sh`；先跑两个最有解释力的变体，避免
在 R6 尚未判定前无依据地占用卡。

## R8：几何条件的融合后 3D 残差（已实现，待 R7 完成后启动）

R7 暴露的缺陷是“无条件修正”不能区分不同视角组合。R8 不再把单一可靠性
标量作为 attention bias，而在 PFT 融合之后将每个关节的 4D 射线法向矩阵
特征（归一化特征值对数 + 平均置信度）与 `pft_features` 一起送入零输出
MLP，直接产生 3D 残差：

```
condition_j = [log(lambda_1/sum lambda), log(lambda_2/sum lambda),
               log(lambda_3/sum lambda), mean_confidence]
delta_j = MLP([pft_features_j, condition_j, joint_embedding_j])
```

输出层零初始化，关闭时完整 H76 identity 已验证 `maxdiff=0.0`；只训练约
`(256+4)*64 + 64*3` 量级的 adapter，不改变 RUMPL 的 VFT/PFT/tri-anchor。
这条路线与 R7 的区别是校正显式依赖相机几何条件，目标正是解释 R7 的泛化
退化。启动器：`launch_R8_geometry_conditioned_output_20260809.sh`，计划先跑
`lr=1e-5` 和 `1e-4` 两组。
